# CIS 295 Student Portfolio

This project deploys to `/<your-slug>/portfolio/` (and visiting `/<your-slug>` automatically
redirects here).

It starts intentionally plain and unstyled—just a clean semantic HTML index linking each week's
deployed work (`../week1/` through `../week8/`) and your final project (`../final/`). Links to weeks
you have not deployed yet show a friendly "Not found — coming soon" page until you publish them.

Feel free to customize, add stylesheets or subfolders inside `projects/portfolio/`, and expand this
into your full Developer Portfolio during Week 10.
